# yamem

Минимальный навык проектной памяти для AI-агентов. Специально сделан простым: без БД, без отдельного сервиса, без обязательных скриптов. Основная цель - простота и естественное ведени памяти без каких-либо правил и требований к пользователю. 200 строк и все.

Изначально это был админ Вася, который со временем мутировал в простой универсальный навык для случаев, когда нет нужды в сложных и емких системах управления памятью.

Для подключения достаточно положить файл навыка любым способом в каталог навыков для вашего агента и желательно (но не обязательно) прописать одну строчку в системный промпт агента.

Что будет падать в память (в .agents/memory/):

- факты и контекст проекта;
- краткий дневник работ (но при необходимсти с подробностями в отдельных файлах в memory/tasks/YYYY-MM-DD-topic);
- активные и завершённые задачи;
- тематические заметки и выученные "уроки";
- артефакты по отдельным задачам.

## Как работать

Исходим из того, что наш проект - git репозиторий.

При старте агент попробует получить обновления из origin (удаленного репозитория, если есть), "вспомнит", что как устроено и что было за последнуюю неделю.

Далее можно спрашивать, какие есть задачи в бэклоге ("что у нас в отложках?", "что в бэклоге?" и т.п.), обсуждать текущие вопросы и че как, командовать что делать.

Агент в ходе общения будет самостоятельнообновлять дневник, бэклог, архив, факты и уроки, артефакты по отдельным задачам, но можно и прямо сказать что-то запомнить.

При работе дольше семи дней агент при начале диалога сначала предложит оптимизировать память: архивировать старые задачи, объединить похожие факты, удалить неактуальное, вынести что-то в общую память и т.п. Можно попросить в любой момент: "оптимизируй память"

## Общая память

По сути это подкаталоги в каталоге .agents/memory/shared/, котрыми можно обмениваться с другими агентами. Наример admin-recipes, 1c-dev, accounting, Внутри md-файлы с описанием универсального полезного опыта, рецептов и граблей. Удобно их делать сабмодулями и шарить через github. Если появился некий опыт, который может быть неоднокртано полезен - стоит разместить его именно здесь.

Наполнение происходит при выполнени оптимизации (см. ниже), либо по требованию.

## Установка

Нужно любым способом положить файл навыка в .agents/skills/memory/

Можно просто скопировать, а можно сделать симлинк. Если не хочется тащить навык в git, можно добавить его в gitignore.

Также можно подключить его как submodule:

```bash
git submodule add https://github.com/rsyuzyov/yamem .agents/skills/memory
git commit -m "feat: add yamem skill"
```

Обновление:

```bash
git submodule update --remote .agents/skills/memory
git commit -m "chore: update yamem"
```

Лично я предпочитаю сабмодули - можно править и сразу пушить, можно обновиться, сказав агенту обновить сабмодули.

## Подключение к агентам

Каждый агент читает навыки из своей папки, поэтому нужно создать симлинк на навык в папке навыков каждого агента.

| Агент       | Папка навыков     | Команда                                                                              |
| ----------- | ----------------- | ------------------------------------------------------------------------------------ |
| Antigravity | `.agents/skills/` | Ничего не нужно — читает напрямую                                                    |
| Claude Code | `.claude/skills/` | `mkdir -p .claude/skills && ln -s ../../.agents/skills/memory .claude/skills/memory` |
| Codex       | `.codex/skills/`  | `mkdir -p .codex/skills && ln -s ../../.agents/skills/memory .codex/skills/memory`   |
| Cursor      | `.cursor/skills/` | `mkdir -p .cursor/skills && ln -s ../../.agents/skills/memory .cursor/skills/memory` |
| Другие      | Зависит от агента | Создать симлинк по аналогии или указать путь в system prompt                         |

## Системный промпт

"Для надёжности" стоит добавить в системный промпт или промпт проекта:

```text
Если в проекте есть .{my_agnet}/skills/memory/SKILL.md, прочитать его в начале работы полностью и выполнить стартовые инструкции.
```

## Согласованность и актуальность

Навык не требует строгой консистентности, согласованности и актуальности - если затащить обновления из origin не удастся, агент сообщит `memory not synced` и продолжит работу.
Если требуется прям надежность-надежность и точность-точность, то лучше сразу проходить мимо. Проект дает уровень обычного рядового инженера, который большую часть времени норм, но может иногда ошибиться или что-то забыть.

## Безопасность и чувствительные данные

Используйте gitleaks!

Навык предписывает:

- Не хранить пароли и секреты в памяти.
- Секреты хранить в `.env` или другом внешнем хранилище.
- В памяти записывать только имя переменной или описание, где искать секрет.
