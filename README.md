# yamem

Минимальный навык проектной памяти для AI-агентов. Специально сделан простым: без БД, без отдельного сервиса, без обязательных скриптов.

Для подключения — добавить submodule и прописать одну строку в системный промпт агента.

Что будет падать в память:

- факты и контекст проекта;
- короткий дневник работ;
- активные и завершённые задачи;
- тематические заметки;
- артефакты по отдельным задачам.

## Как работать

Исходим из того, что наш проект - git репозиторий.
При старте агент попробует получить обновления из удаленного репозитория (если есть), "вспомнит", что как устроено и что было за последнуюю неделю.

Далее можно спрашивать, какие есть задачи в бэклоге ("что у нас в отложках?", "что в бэклоге?" и т.п.), обсуждать текущие вопросы и че как, и командовать что сделать.

Агент в ходе общения будет обновлять дневник, бэклог, архив, факты и уроки, артефакты по отдельным задачам.

Но можно и прямо сказать что-то запомнить.

При работе дольше семи дней агент при начале диалога сначала предложит оптимизировать память: архивировать старые задачи, объединить похожие факты, удалить неактуальное и т.п. Можно попросить в любой момент: "оптимизируй память"

## Установка

### Вариант A: Git submodule (рекомендуется)

Подключить как submodule — тогда навык обновляется командой `git submodule update --remote`:

```bash
git submodule add https://github.com/rsyuzyov/yamem .agents/skills/memory
git commit -m "feat: add yamem skill"
```

Обновление:

```bash
git submodule update --remote .agents/skills/memory
git commit -m "chore: update yamem"
```

### Вариант B: Скопировать вручную

Скопировать папку `.agents/skills/memory/` в проект. Без автообновлений.

## Подключение к агентам

Навык хранится в `.agents/skills/memory/`. Каждый агент читает навыки из своей папки — нужно создать симлинк.

### Antigravity

Ничего дополнительно не нужно — Antigravity читает навыки из `.agents/skills/` напрямую.

### Claude Code

```bash
mkdir -p .claude/skills
ln -s ../../.agents/skills/memory .claude/skills/memory
```

### Codex

```bash
mkdir -p .codex/skills
ln -s ../../.agents/skills/memory .codex/skills/memory
```

### Cursor / другой агент с кастомной папкой навыков

```bash
mkdir -p .cursor/skills          # замени на нужный путь
ln -s ../../.agents/skills/memory .cursor/skills/memory
```

Если агент не поддерживает папку навыков — укажи путь в system prompt (см. ниже).

## Системный промпт

Добавить строку для надёжности (работает для любого агента):

```text
Если в проекте есть .agents/skills/memory/SKILL.md, прочитай его в начале работы и выполни стартовые инструкции.
```

## Важное поведение

Навык не требует строгой консистентности.

Если `git pull --rebase`:

- не нужен;
- не сработал;
- неуместен;
- невозможен из-за локального репозитория без upstream/remote;

агент всё равно продолжает работу и просто пишет `memory not synced`.

## Безопасность

- Не храни пароли и секреты в памяти.
- Секреты держи в `.env` или другом внешнем хранилище.
- В памяти записывай только имя переменной или описание, где искать секрет.

## Минимальный рабочий минимум

Чтобы навык заработал, достаточно:

1. Подключить через submodule или скопировать папку `.agents/skills/memory/`.
2. Добавить одну строку в system prompt или проектные инструкции агента.

Этого достаточно для простого, переносимого и дешёвого по контексту механизма памяти.
